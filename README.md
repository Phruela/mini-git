# Análise Orçamentária

O Setor Público tem dificuldade de saber quais órgãos de fato executam o orçamento. Muitos órgão recebem alta dotação mas não usam, enquanto outros órgãos empenham mais do que a dotação sendo necessario solicitar crédito adicional. 

## Objetivo
Este projeto visa analisar os dados de orçamento para identificar a execução dos órgãos e fornecer insights de como melhorar o planejamento da dotação orçamentária.

## Dados
Os dados foram criados manualmente para simular o orçamento. O arquivo contém 4 registros e 5 colunas.

## Uso
1. Crie uma conta databricks free edition
2. Baixe o arquivo orcamento.csv da pasta dados deste repositorio
3. Faça upload do arquivo csv no databricks
4. Crie um Notebook SQL no databricks, copie as queries e execute as células.

## Design
O desenvolvimento das consultas foi feito em branches. Cada consulta foi desenvolvida em umabranch isolada.
